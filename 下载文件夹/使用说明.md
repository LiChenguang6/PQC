# X2 保存导出版（export3）

安装 [X2-cache-export.apk](X2-cache-export.apk)。版本码 11，包名仍为 `com.example.yinqishe_export`，沿用此前导出版签名，可以直接覆盖更新并保留数据。

1. 按原流程登录、浏览并开始播放视频。
2. 点右侧并排的“下载”“管理”中的“下载”。首次选择一次保存文件夹，之后直接加入后台队列，不再反复弹出文件选择窗口。
3. 可以继续浏览、播放其他视频、返回桌面或熄屏。通知栏显示后台下载状态。
4. “管理”显示任务进度，点任务可取消、重新下载、删除。删除进行中的任务会取消并清理半成品；删除已完成任务只删除记录，保留 MP4。
5. “管理”→“下载设置”可更改保存文件夹和同时下载数量（1–4，默认 3）。更改目录适用于新任务；已有任务继续写入创建时的目录。
6. “管理”→“导出已有缓存”仍可导出本副本已完整缓存的普通 HLS 视频。

建议在系统设置中允许本应用后台运行，并在“下载设置”中按需要设置电池优化豁免。厂商强力省电、用户强行停止或系统限制仍可能中断任务；重新打开管理页可恢复中断任务，恢复方式为重新下载，不是分片断点续传。失败任务若链接已过期，请返回原页面重新播放后新建下载。原生平台下载按钮的行为不由新增下载队列控制。

相关推荐不能继续向下浏览：已针对原应用分页中没有滚动容器的推荐卡片区域加入纵向滚动补丁，适用于 ARM64 和 x86_64。ARMv7（32 位）保留原页面逻辑，尚未修复该滚动问题。真实平台页面在当前云环境无法连接，因此该补丁已做结构分析、指令执行检查和应用启动检查，但尚不能代替手机上实际相关推荐页面验证。

支持普通有限 HLS、标准 AES-128、简单音视频复用主清单和可验证时长的直接媒体。独立音轨、fMP4 MAP、byterange、直播和 DRM/SAMPLE-AES 暂不支持。任务地址和请求信息保存在应用私有目录的加密队列中，不写入公开下载目录；完成后移除该任务的播放请求凭据。

[验证记录](VALIDATION.md)；[补丁与完整 FFmpeg 源码](X2-cache-export-source.zip)。源码不包含原 APK、开发签名私钥或账号凭据。原版与导出版数据独立，原版私有缓存不会自动迁移，不需要卸载原版。
