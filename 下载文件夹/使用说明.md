# X2 保存导出版（export2）

安装 [X2-cache-export.apk](X2-cache-export.apk)，可直接更新此前的导出版，无需卸载。新版名称“X2社·保存导出版”，包名仍为 `com.example.yinqishe_export`，版本码 10。

1. 在导出版正常登录、浏览并开始播放需要保存的视频。
2. 点右侧可拖动的“保存/导出” → “保存当前播放视频”。
3. 点“选择位置并下载 MP4”，在系统窗口选择目录并保存。
4. 保持页面打开，等待“已保存 MP4”，再到所选目录播放或分享。

此入口无需先点原来的下载按钮，也不依赖它完成缓存。原下载按钮仍可能显示“下载失败”；其平台接口的真实失败原因尚未确定。新增入口使用点击时正在播放的视频地址，若已暂停、正在切换或有多个视频同时播放，会要求重新选择。

已经在本导出版完成下载的缓存仍可通过“保存/导出” → “导出已下载缓存”保存。原版本与导出版的账号、设备身份和私有缓存独立，不自动迁移；不需要卸载原版。

支持普通有限 HLS、标准 AES-128、简单音视频复用的主清单和可验证时长的直接媒体。独立音轨、fMP4 MAP、byterange、直播和 DRM/SAMPLE-AES 等暂不支持，会显示具体错误。链接过期时，请返回重新播放后再保存。取消可能需要等待网络超时，失败或取消会清理临时媒体、密钥及目标半成品。

验证结果见 [VALIDATION.md](VALIDATION.md)。云端对受控素材的测试不能代替平台真实影片验证：当前云环境无法连通该平台后台，尚不能保证所有真实视频成功。ARM64/ARMv7 已编译，实际执行测试来自 x86_64 Android 模拟器。
