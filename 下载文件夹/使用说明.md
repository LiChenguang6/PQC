# X2 export21：播放器本地许可状态实验

本版以 export20 和用户确认能播放的原版回归逻辑为基础。比较发现：“视频”和“禁区”共用按视频 ID 获取详情的接口、播放地址字段和播放器。禁区多一个本地会员入口检查；能否正常播放还受详情中的 canWatch 和返回视频源影响，不存在可直接复制的另一套免费 VIP 账号权限。

## 使用

直接覆盖安装，然后进入 管理 → 下载设置：

1. 开启“开发测试：禁区入口（仅本地）”。
2. 开启新增的“开发测试：播放器许可状态（实验）”。
3. 退出当前视频并重新打开禁区视频。开启或关闭许可实验均需重新打开视频，才会重新传递许可状态。

新开关默认关闭，开关保存后重启保留。若出现异常，关闭“播放器许可状态（实验）”并重新进入视频，即恢复 export20 的原版可播放状态传递。

## 实现与范围

许可实验在详情数据传给播放器的位置，只把两个本地状态（VideoPlayByVideoIdController.field_5f 和 PlayerController.field_47）设为正常可播放的布尔值。关闭时按原样读取详情值，已是可播放的免费视频开启后仍传递同样值。

保留初始化、全部进度回调、播放进度记录、广告开关、源去重及文件管理。不同于旧版直接跳过试看回调，不改详情解析结果、不改账号、令牌、服务器请求或播放地址；原模型 canWatch 仍保留服务器值。

这是用于“服务器已提供完整源、但客户端本地许可限制”情况的实验。服务器仅提供十几秒清单、缺少后续分片或拒绝访问时，本地状态修改不能提供完整内容。尚未验证真实禁区完整播放，不代表已开通账号 VIP。
