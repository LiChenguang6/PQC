# export15 本地视频封面列表与播放详情诊断

版本9.9.9-export15，版本码23。沿用原导出版签名和包名，直接覆盖安装，保留下载记录、保存目录授权和设置。

## 下载完成页：封面卡片

“管理 → 下载完成”采用类似视频网站的视频卡片：16:9大封面、标题、右下角时长、保存状态。封面由已保存MP4在后台提取，支持系统授权的保存目录，不访问外网。

- 普通点击封面或卡片：调用手机已安装的视频播放器播放，附带该文件的临时读取授权。
- 长按卡片：保留仅删除记录、删除记录及MP4等操作。
- 点击“多选”后点击卡片只切换选择；不会启动播放，右上角显示选择状态，继续使用批量删除。
- 两个后台线程生成封面，内存缓存上限12MiB，磁盘缓存最多128张/32MiB，保存在应用私有缓存目录，不向下载目录添加图片。再次打开优先使用缓存。
- 文件暂时不可读、视频格式无法提取预览或没有视频帧时，显示占位封面，原有记录和管理功能保留。已缓存的预览不是文件仍然存在的证明。普通清除应用缓存会移除封面缓存，不影响下载MP4。

## 继续定位12秒播放清单

**指定真实视频的完整播放尚未修复或验证。本版没有修改服务器账户、认证令牌或出站VIP声明。**

已收到export14实测：HTTP200、HLS3个分片、总时长12.067秒、ENDLIST=1。本版增加详情数值与播放器地址的精确绑定，以确认标称时长与实际清单是否不一致。

1. 保持手机原有VPN，在“管理 → 下载设置”开启“开发测试”。
2. 重新打开目标视频，实际播放几秒。
3. 30秒内进入“管理 → 下载设置 → 检查当前播放源（复制）”。复制全部文字发回，无需USB或Root。

新增字段：

- detail_match=exact_uri：详情采样对应的完整播放地址与播放器完全一致；none表示未能对应，不能解释为权限标记。
- detail_video_id：视频编号。
- detail_play_time_raw：详情模型中的原始playTime整数，不擅自换算单位。
- detail_can_watch：原始可播放布尔标记，1为true，0为false，-1为未识别；不是本地开发开关覆盖后的判断。
- detail_video_type / detail_reason_type：原始类型/原因数字，不猜测其业务含义。

若详情时长明显超过清单时长且can_watch=0，支持详情与本次下发媒体不一致的判断，但仍不能只据此认定具体会员策略。若detail_match=none，请确认重新进入目标视频后再检查。仅复制数值；不会把视频路径、标题、鉴权信息或请求头复制出来。

原检查仍报告清单分片数、EXTINF总时长、ENDLIST和加密标记。主清单检查选择最高带宽变体；重新请求所得响应可能不同于原播放响应。检查不读取视频分片和密钥；来源上下文只在进程内短暂保存30秒。详情复制使用无调用的Dart叶子钩子及序列校验，不保留Dart对象指针；支持锁定APK的ARM64/x86_64，32位无法匹配时返回none。
