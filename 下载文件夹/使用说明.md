# X2 社保存导出版 export13

版本9.9.9-export13，版本码21。沿用原导出版签名与包名，**覆盖安装，不要先卸载**，保留下载队列、目录授权和配置。

## 已完成视频：选择是否删除 MP4

- 在“管理 → 下载完成”中，普通点击仍播放；长按可选“仅删除记录（保留 MP4）”或“删除记录及 MP4 文件”。
- 点击“多选”选择视频，再点“删除”，同样可选择上述两种方式。
- 同时删除文件需要二次确认；后台逐项处理，不占用下载线程。成功后移除记录，文件删除失败时保留记录并显示原因。若文件已被其他程序移走／删除，或原保存目录权限失效，可检查后重试，或选择仅删记录。
- 未完成任务删除仍取消下载并清理半成品。暂停、继续、取消、重试及1–32并发设置保留。

## 名称、图标与开屏

入口：“管理 → 下载设置 → 名称、图标与开屏”。

1. 更改显示名称、选择桌面图标，点击“创建／更新桌面入口”。首次添加按系统桌面提示确认；已有入口会更新。
2. 这是自定义桌面快捷方式，**原应用列表的名称与图标保留**。部分系统会给快捷方式加原应用角标或要求桌面权限。
3. “选择应用开屏图片”设置应用内部启动封面，下次冷启动显示，主页导航构建完成后自动移除；初始化照常执行，不增加强制倒计时，可点击“关闭封面”。Android系统最开始显示的图标由系统控制。
4. 图片复制并缩放到应用私有目录，之后修改原相册文件不会影响已保存外观。“恢复默认外观”只清除名称和两张外观图片，不碰下载记录或MP4；已有桌面入口可再点击创建／更新恢复。

## 禁区20秒暂停：仍需真实设备诊断

已收到反馈：红米Turbo4Pro / Android16安装export10并开启测试后仍约20秒暂停／回退。本版**没有声称已解决该设备的完整播放**。

保留本地禁区判断及两处20秒分支覆盖；同时把开发开关的原生同步从主页焦点／首帧条件中独立出来，设置切换后立即同步，并增加命中计数及只读播放状态。

请在这台设备上：

1. 覆盖安装后，在下载设置保持开发测试开启。
2. 重新进入禁区视频，播放到暂停／回退出现。
3. 立即打开“管理 → 下载设置 → 播放诊断（复制）”，复制后发回文字。保留最近45条记录，建议停止后马上操作。

诊断只包含版本、运行架构、系统版本、配置与同步后的原生开关、暂停判定进入／跳过计数，以及播放器进度、时长、暂停／结束／空闲标记；不含视频地址、标题、请求头、账号或密钥。无需Root、USB调试或连接电脑。打开管理页本身可能暂停播放器，因此需要看之前的时间序列。

若 bridge=unavailable 表示未找到原生桥；pause_seen / pause_skipped 是该补丁在超过20秒时进入／跳过暂停回退的次数，不能单独当作完整播放证明。真实流及服务器是否提供完整内容仍未在云端验证。
