# X2 保存导出版 export17

在“管理 → 下载设置”可开关“显示视频预览图”，并选择“预览每行数量”：1、2、3 或 4 个。配置自动保存，同时作用于“下载完成”和“视频预览”。关闭预览图后仍显示标题并可点击播放，不提取新封面。

“管理”顶部原“导出已有缓存”已替换为“视频预览”。新页面仅展示下载完成的本地视频封面与标题，隐藏管理按钮，保留系统状态栏和导航栏，支持滑动浏览；点击视频交给本机支持 MP4 的播放器播放。系统返回手势回到管理页。它不是自动连续播放的短视频播放器。

原“导出已有缓存”移到“下载设置”中。管理页的下载、暂停、批量操作与两种删除方式保留。视频预览页不执行删除等管理操作。

沿用原签名，可覆盖安装 export15，保留任务、文件夹配置与文件。请勿先卸载；文件权限失效时需重新选目录。

本版停止排查先前的播放时长问题，没有修改账户权限或平台视频来源。
